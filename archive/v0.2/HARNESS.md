# Live Harvest Design Harness v0.2

Канон визуального языка. Читать в режиме Harvest Designer.

## Философия

Live Harvest — персональная операционная система жизни. Интерфейс должен хотеться открывать ежедневно: спокойный, плотный, премиальный, не игрушечный.

Формула: **Linear** (эстетика) + **Fallout** (портрет/квесты) + **Obsidian** (знания/связи).

Не делать: админку, CRM, типовой AI-dashboard, кислотный CRT, огромные карточки, бессмысленные градиенты.

## Типографика

Локальные файлы в `harvest-ui/fonts/` (без обязательного CDN):

- UI: **IBM Plex Sans** (400/500/600/700)
- Data / meta: **IBM Plex Mono** (400/500)

Шкала:

- Title page: 22–28 / 600–700
- Section: 13–14 / 600
- Body: 13–14 / 400
- Meta: 11–12 mono / 500

Межстрочный 1.4–1.5. Длина строки контента ≤ ~70ch где уместно.

## Layout

- Компактный sidebar ~220px, группы: Life / Intelligence / Modules
- Контент: max-width ~1120px, padding 20–28
- Сетка dashboard: 12-col mental model; блоки 4/6/8 ширины
- Плотность высокая; воздух через ритм, не через пустые «hero-пустыни»

## Компоненты

- **Panel** — `#161A21`, border `#2A303A`, radius 10
- **Nav item** — height ~32, active = soft accent fill + left bar
- **Chip / epistemic** — mono 11px, цвет точки
- **Quest row** — amber marker, title + meta
- **Balance bar** — нейтральные сегменты без «оценки личности»; empty = пунктир
- **Empty state** — коротко + что заполнить; без извинений
- **Demo badge** — «демо» серым chip

## Навигация

Life: Обзор, Личность, База знаний, Цели, Проекты, Финансы, Здоровье, Планирование, Дневник, Ретроспектива  
Modules: Harvester, Advisor, Развиватор  
Неактивные разделы — stub с «скоро», без фейковой функциональности.

## Эпистемика

Всегда различать: факт / намерение / гипотеза / открытый вопрос.  
Гипотезы ИИ не стилизовать как факты. Источник — ссылка-заглушка до wiring.

## Геймификация

Допустимо: Main Quest, Side Quests, Checkpoints, Achievements, привычки, серии, прогресс по измеримым целям.  
Запрещено: XP, уровень личности, псевдостаты, дерево прокачки без решения, награды ради кликов.

## Анимации

- 120–180ms ease на hover/active
- Смена view: лёгкий fade 150ms
- `prefers-reduced-motion: reduce` — отключить декоративное
- Без бесконечных pulse/glow

## Состояния

- loading — skeleton lines, не спиннер на весь экран
- empty — приглашение к действию (вне UI: Harvester)
- demo — явная метка
- stub route — название раздела + «в разработке»

## Анти-slop (из frontend-design / impeccable, локально)

Не использовать по умолчанию: purple glow kits, Inter-everywhere, cream+terracotta landing, acid green CRT, одинаковые rounded cards с мягкой тенью везде, ALL-CAPS eyebrow над каждым заголовком, «→» на каждой кнопке.
