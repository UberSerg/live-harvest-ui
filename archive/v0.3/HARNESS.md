# Live Harvest Design Harness v0.3

Канон визуального языка Personal Command Center. Читать в режиме Harvest Designer.

## Формула

**Linear** — chrome, плотность, нейтральный графит, ясная иерархия.  
**WHOOP** — статус и динамика состояния (кольца/орбиты, не фейковые метрики).  
**Obsidian** — знания и связи; SoT вне UI.  
**Raycast** — быстрые действия, фокус, клавиатурная лёгкость (задел).  
**Fallout** — квесты и портрет персонажа без XP/уровней.

Продукт: премиальный Life OS, не админка и не AI-dashboard.

## Антипаттерны (запрет)

- Однообразная сетка одинаковых карточек
- Мелкий «серый на сером» текст как основной
- Моноширинный шрифт для обычного body-текста
- Кислотный CRT / сильный glow / фиолетовые градиентные киты
- Декоративные графики, выдаваемые за аналитику
- XP, уровни личности, псевдостаты

## Типографика

Локально: **IBM Plex Sans** (UI + body).  
**IBM Plex Mono** — только meta/чипы/коды, не абзацы.

Шкала:

- Display: 40–48 / 600
- Title: 28–32 / 600
- Section: 18–20 / 600
- Body: 15–16 / 400, line-height 1.5
- Meta: 12 mono / 500

Крупная иерархия обязательна: заголовок экрана доминирует над панелями.

## Layout

- Sidebar ~240px, группы Life / Modules
- Command Center: **асимметричный bento**, не 12 одинаковых плиток
- Сигнатурный блок **«Моя вселенная»** — орбитальный граф (SVG), центр = пользователь
- Портрет личности — character sheet: ядро + тематические кластеры, не длинный README

## Компоненты

- **Bento cell** — разные размеры (hero / wide / tall / compact)
- **Universe** — орбиты + узлы; клик раскрывает панель аспекта (read-only)
- **Quest** — warm accent, checkpoint строкой
- **Wave chip** — крупнее, с лёгким hover
- **Epistemic mark** — цветная точка + подпись в легенде
- **Empty** — честно «нет данных», без спиннеров-заглушек метрик
