# Шаблон финансового наблюдения

Бланк моста «класс сверки → наблюдение». Пока поля не заполнены из ответа API или из слов человека, это не финансовая рефлексия и не факт о книгах владельца.

`status` карточки — по `core/STANDARD.md` (`draft`, пока запись не стала подтверждённым каноном). `finance_observation_status` его не подменяет.

Допустимые `finance_observation_status`: `open` (вопрос не закрыт), `noted` (человек сам дописал, что проверил). Команда ставит только `open`.

`reconciliation_class` — пусто в бланке. После черновика это одно из трёх слов: `matched`, `mismatch`, `missing`. Токен ledger `no_totals` в наблюдении записывается как `missing`.

Поля суммы, остатка, маски счёта, номера счёта и проводки в этом бланке отсутствуют. Их сюда не копировать.

`goal` необязателен. Пустая строка значит, что цель не подтверждена. Если цель есть, это одна вики-ссылка, и ссылка не назначает ответственность.

`hypothesis` необязательна. Пустая строка значит, что предположение не записано. Команда гипотезу не сочиняет.

При копировании: новый `id`, снять `synthetic`, источник заменить на реальный ответ. Этот файл команда `draft-observation` не перезаписывает.

## Команда

`python tools/lh_finance_reflect.py status` печатает класс сверки и булевы флаги полноты. Если локальный API `http://127.0.0.1:8777` не отвечает, в ответе `detail: offline`. Суммы в вывод не входят.

`python tools/lh_finance_reflect.py draft-observation --out PATH` создаёт черновик в `harvest/Мозг/_system/` или в `harvest/Мозг/_system/stm/items/`. В теле есть строка `сверка: matched|mismatch|missing` и открытый вопрос `что проверить`. Совета в тексте нет.

Проверка без живого API: `python -m unittest tools.test_lh_finance_reflect -v`.

## Сверка

Класс, не сумма. Пока бланк пуст, класса нет.

## Полнота

Только булевы флаги, если они пришли из ответа. Чисел здесь нет.

## Гипотеза

Пусто, пока человек сам не сформулировал предположение.
