# Шаблон решения с исходом

Бланк для **новой** карточки `harvest/Решения/`. Этот файл сам решением не является. Пять уже существующих карточек по нему не переписывать.

При копировании заменить `id`, снять `synthetic`, поставить `type: decision`, заполнить `expected_outcome` и `review_date`, оставить `actual_outcome` и `lesson` пустыми, поставить `outcome_status: pending`. Пустые факт и урок не заполнять прогнозом.

Поля YAML для новой карточки. Старые файлы без них остаются верными:

| Поле | Значение |
|---|---|
| `expected_outcome` | ожидание одной фразой. В бланке пусто |
| `review_date` | `YYYY-MM-DD` или пусто |
| `actual_outcome` | пусто, пока нет факта |
| `lesson` | пусто, пока нет факта |
| `outcome_status` | `pending`, `reviewed`, `recorded` или `not_applicable` |

`reviewed` пишет `python tools/lh_decisions.py record-outcome`, когда человек передал факт и урок. `recorded` — прежнее имя уже закрытого исхода, список ожидания его не показывает. `not_applicable` — у этого бланка и у карточки, которой исход не нужен.

`status` карточки по-прежнему из словаря: `draft`, `active`, `paused`, `done`, `cancelled`, `superseded`. `outcome_status` не подменяет его.

## Проблема

Какое затруднение человек назвал. Черновик обсуждения сюда не переносить как принятое.

## Варианты

Только варианты, которые реально рассматривались. Не придумывать третий путь от модели.

## Основания

На чём держится выбор. У каждого основания есть источник.

## Допущения

Что считается верным, пока не проверено. Допущение не записывать как факт.

## Выбранное

Писать как решение только после явного принятия. Иначе оставить карточку в `draft`.

## Ожидаемый результат

Что должно измениться к дате пересмотра. Это ожидание, не отчёт о факте.

## Дата пересмотра

День, когда спросить фактический результат. Поле `review_date` дублирует эту дату для поиска.

## Фактический результат

Пусто, пока человек не сообщил, что произошло.

## Урок

Пусто, пока нет фактического результата. Урок не повышать до правила в `core/`. Связь с целью или проектом — полем `related`, не только вики-ссылкой в абзаце.

## История

- YYYY-MM-DD — карточка создана с ожиданием — источник
