# Live Harvest UI

Personal Command Center (static, read-only). Version **0.3**.

## Quick start

```bash
cd live-harvest-ui
python -m http.server 8765
```

Open http://localhost:8765/

## Layout

- `index.html` / `styles.css` / `app.js` / `data.js` — app
- `design/HARNESS.md` — design canon
- `icons/` — Lucide SVG (local)
- `fonts/` — IBM Plex (local)
- `review/` — visual QA screenshots
- `archive/` — previous UI versions
- `CHALLENGE.md` — critique brief for external review

## Privacy

Demo/portrait sample only. Not the private `harvest/` knowledge base.
