# Live Harvest Design Harness v0.4

Канон после critical redesign. Читать в режиме Harvest Designer.

## Формула

Качество взаимодействия уровня Linear, характер — редакционный Life OS.  
WHOOP — только честный статус областей, без фейковых метрик.  
Obsidian — знания в SoT; UI показывает срезы.  
Fallout — лёгкая метафора квестов/checkpoint без XP.

Не копировать Linear UI. Не делать AI-dashboard.

## Антипаттерны (запрет)

- Фиолетовое свечение / indigo glow как «премиум»
- Одинаковые bento-карточки на весь экран
- Декоративные градиенты без смысла
- Мелкий серый текст как основной body
- Россыпь бейджей и фальшивые KPI
- Пересоздание SVG/DOM на каждый hover/click
- CSS `transform` на SVG `<g>` с атрибутом `transform` (ломает позицию)
- Меню-заглушки, выдаваемые за готовые разделы

## Экраны

Рельс после BRAIN-UI-EVOLUTION-01 — четыре места, не восемь отделов:

1. **Сегодня** — первый кадр (кто, фокус, контрольная точка, фраза внимания по статусам узлов, один шаг, вопрос). Ниже: цель, компактная вселенная, список шагов; остальное в `<details>`. Сумм капитала здесь нет. Вопрос не дублируется отдельной «рекомендацией».
2. **Мозг** — одна комната. Линзы Личность · Рефлексия · Исследования · Развитие читают тот же снимок. Личность — цельная страница, не grid кластеров. Маршрут `#self` открывает линзу Личность. Запись ответа и захват **файлом из UI** не делаются. Линза «Рефлексия»: кнопка «Уточнить рефлексию» копирует в буфер промпт с маркером `LH-UI-REFLECT` (текущий вопрос + контекст open). Пользователь вставляет промпт в Cursor, дописывает ответ; агент пишет `harvest/` + `overlay.json` + `python tools/lh_ui_snapshot.py` и отвечает блоком `LH-UI-REFLECT-APPLIED`. Это не отправка наружу. Линза «Исследования» может скопировать синтетический пакет из `demo/research-packet.prompt.txt` в буфер. Пустой список гипотез примерами не заполняется.
3. **Моя вселенная** — исследование областей
4. **Капитал** — вкладки внутри раздела (обзор / операции / счета / бюджет / обязательства / прогноз / FI); sticky chrome; период по умолчанию = текущий календарный месяц (1 → последний день); hero = ликвидность + план (позитив), чистый капитал и долг только в `<details>`; без bento и fake KPI; категории/KPI → drawer со списком операций (без полной карточки); счета группированы, клик → операции; **Импорт выписки**; doughnut = экон. расходы; банковский оборот ≠ экономика

Палитра (Ctrl+K) только переходит в эти места и линзы. Команды без записи в данные не показываются.

Остальное — блок «Позже», без fake nav. Спека: `design/BRAIN-UI-EVOLUTION-01.md`.

## Universe (техника)

- SVG рендерится **один раз** на mount
- Выбор узла = class `is-active` + обновление detail
- Event delegation на host
- Hover/focus анимируют `circle.leaf` (stroke/fill), не transform группы
- Keyboard: Tab, Enter/Space, стрелки
- `prefers-reduced-motion`

## Геймификация

Main goal + checkpoint + actions. Без XP/уровней/псевдостатов.
