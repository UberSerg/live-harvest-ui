# Live Harvest Design Harness v0.4

Канон после critical redesign. Читать в режиме Harvest Designer.

## Формула

Качество взаимодействия уровня Linear, характер — редакционный Life OS.  
WHOOP — только честный статус областей, без фейковых метрик.  
Obsidian — знания в SoT; UI показывает срезы.  
Fallout — лёгкая метафора квестов/checkpoint без XP.

Не копировать Linear UI. Не делать AI-dashboard.

## Антипаттерны (запрет)

- Фиолетовое свечение / indigo glow как «премиум»
- Одинаковые bento-карточки на весь экран
- Декоративные градиенты без смысла
- Мелкий серый текст как основной body
- Россыпь бейджей и фальшивые KPI
- Пересоздание SVG/DOM на каждый hover/click
- CSS `transform` на SVG `<g>` с атрибутом `transform` (ломает позицию)
- Меню-заглушки, выдаваемые за готовые разделы

## Типографика

IBM Plex Sans. Mono — только meta/labels.  
Display ~48, section labels uppercase mono 11, body 16, lead 18–20.  
Пустое пространство — часть композиции.

## Экраны

Рабочие:

1. **Обзор** — профиль, фокус, цель, компактная вселенная, действия, рекомендация; остальное в `<details>`
2. **Личность** — цельная страница, не grid кластеров
3. **Моя вселенная** — исследование областей
4. **Капитал** — вкладки внутри раздела (обзор / операции / счета / бюджет / обязательства / прогноз / FI); без bento-сетки и fake KPI; долг не доминирует эмоционально

Остальное — блок «Позже», без fake nav.

## Universe (техника)

- SVG рендерится **один раз** на mount
- Выбор узла = class `is-active` + обновление detail
- Event delegation на host
- Hover/focus анимируют `circle.leaf` (stroke/fill), не transform группы
- Keyboard: Tab, Enter/Space, стрелки
- `prefers-reduced-motion`

## Геймификация

Main goal + checkpoint + actions. Без XP/уровней/псевдостатов.
