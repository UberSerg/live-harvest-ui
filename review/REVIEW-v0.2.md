## Что работает

- Graphite + indigo акцент читается как Linear-like, без кислотного CRT v0.1
- IA: жизнь + модули; stubs без фейковой функциональности
- Dashboard блоки по ТЗ; empty states без выдуманных метрик
- Main/Side quests — лёгкая геймификация без XP/уровней
- Портрет с эпистемикой; будущие действия собраны в одном ряду
- Локальные шрифты IBM Plex; CDN не обязателен

## Найдено и исправлено в проходе

1. Пустые полосы баланса выглядели как «полный» прогресс → пунктирный трек + width 0
2. Кнопки «Оспорить/Дополнить» на каждой секции шумели → один toolbar сверху
3. Смена hash без перезагрузки не обновляла view → `hashchange` + `inert`/очистка скрытых view

## Остаточный долг

- Нет автосборки из `harvest/*.md`
- Иконки — текстовые глифы; позже SVG-набор
