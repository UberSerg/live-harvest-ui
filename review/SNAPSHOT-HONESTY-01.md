# Снимок 0.4.2 — убраны заготовки

Дата: 2026-11-25. Срез: честная сборка, cut #1 из CHALLENGE-01.

`tools/lh_ui_snapshot.py` больше не дописывает эпистемологию и утренний текст. Поле попадает в снимок только если оно скопировано из секции карточки (`Факты`, `Гипотезы`, `Открытые вопросы`, `Намерения`) или явно задано в `overlay.json`. Иначе значение `null` или пустой список. UI уже показывает пустые состояния («Фокус в снимке не задан», «Контрольная точка не задана», «В снимке нет вопроса»).

## Что код больше не выдумывает

- Запасные пункты с `ep: fact` для мышления, ценностей, интересов, компетенций, развития, желаемого образа.
- Гипотезу, которую скрипт дописывал к кластеру «Мышление», и три заготовки кластера напряжений.
- Константную контрольную точку и укороченный заголовок цели, помеченные `literal`.
- Фокус, стадию, вопрос развиватора и три шага по умолчанию, если их нет в overlay.
- Авторские blurbs областей (семья, финансы, проекты, работа, обучение), помеченные `literal` только потому, что файл существует.
- Список достижений, «измеримый» прогресс, ленту recent и историю портрета из констант скрипта.
- Короткий девиз, роль «основатель Live Harvest» и чипы ценностей, если соответствующей строки в карточке нет.

Наблюдения из карточки не помечаются как `fact`. Кластер «Сильные стороны» остаётся пустым, пока нет секции с известной меткой.

## Ломающее

- Ключи снимка те же. `focus`, `stage`, `checkpoint`, `detail`, `razvivator.text`, blurbs и пункты кластеров могут стать `null` / `[]`.
- `profile.values` — дословные части строки «Ключевые ценности», без переименования в «Спокойствие» / «Честность».
- `mainQuest.title` — заголовок H1 карточки цели, не укороченная константа. `detail` и `checkpoint` задаёт только overlay.
- Blurb области — первый пункт `## Факты` связанной карточки (обрезка по границе слова до 160 символов) или `null`. Статус `watch` сам по себе больше не ставится.
- Следующий полный прогон `python tools/lh_ui_snapshot.py` заново скопирует пункты карточек в локальный снимок, включая первый факт финансовой цели. Этот проход так не делал.
- `--also-demo` по-прежнему запрещён.

## Личный снимок

`harvest-ui/snapshot.json` и `data.js` не пересобирались из карточек. Из них только сняты строки заготовок. Текст overlay (фокус, стадия, шаги, вопрос, blurbs финансов/проектов/работы, кластер «Созидание») оставлен. Пустые кластеры означают «заготовка удалена», а не «в карточке пусто».

## Демо

Синтетический снимок собирается только из `harvest-ui/demo/fixture/` и `harvest-ui/demo/overlay.demo.json`:

```
python tools/lh_ui_snapshot.py --write-demo
```

Проверка, что снятые заготовки не вернулись:

```
python tools/test_lh_ui_snapshot.py
```

## Покрытие источников

`DEFAULT_RENDERED_SOURCES` снова экспортируется: это список файлов, которые `build_literal` читает, а не запасной текст. `snapshot-sources.yaml` `rendered` совпадает с ним. Аренда, волны вдохновения и `Финансы/Кеш — текущий.md` перенесены в `extra_unrendered`: сборщик их не читает, контрольная точка и блип финансов из них не появляются. `--coverage` по-прежнему печатает JSON и не пишет `snapshot.json` / `data.js`. `meta.sources` добавляется только при сборке личного `harvest/`, не в демо и не в фикстуру. `harvest-ui/demo/data.demo.js` заново записан из `snapshot.demo.json`, чтобы пара совпала: в JSON уже был синтетический блок `research`, в JS его не было.
